# DustJS
A WIP WebGL application for creating models or rendering scenes. Not meant to be used by the general public (yet?) as the code is poo poo for now and WIP.

## Specifications
- Uses a fixed time step for physics and interpolation for rendering at above 60fps (interpolation is not used if the refresh rate is 60fps)
- Goal is to be lightweight (i.e. run splendidly on a chromebook)
